`Ucl.Fixture.Native.dll` is generated by `tests/Ucl.StubBuilder`: a minimal x86-64 PE32+ image with one empty
section and no CLI (COR20) header, standing in for an unmanaged plugin such as a native Windows DLL. It has
no code; it only has to look like a native DLL to a PE reader and to the C# compiler (which rejects it as a
reference with CS0009).
